**Room temperature Compliance Monitoring System**

## Background
Scientist needs to know throughout the year temperature deviation occur in the laboratory to check either the environmental condition affected there experiment result.

Currently the temperature readings stores in Excel file and review manually
Increase the human error and time consuming

For safe development and ensure reproducibility, the secure Python virtual environment is used.
Result shows how good coding practices and automated data analysis, reduce operation risk and improve efficiency.


The exercise demonstrates how small, clear tests and defensive coding habits reduce risk in AI projects.
