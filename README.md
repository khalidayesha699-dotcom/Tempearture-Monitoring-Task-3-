# Task 3 — Upload Secure Environment & Process Automation

## Project Title
**Compliance Monitoring System Of Laboratories Temperaure**

## Background
Scientist needs to know throughout the year temperature deviation occur in the laboratory to check either the environmental condition affected there experiment result.
This project is to highlight the period of year when room temperature deviation occur.
Currently the temperature readings stores in Excel file and review manually
Increase the human error and time consuming
Project automate the temperature deviation detection using the excel data
Compliance monitoring is possible after getting automated report and clear visualisations through graps
For safe development and ensure reproducibility, the secure Python virtual environment is used.
Result shows how good coding practices and automated data analysis, reduce operation risk and improve efficiency.


The exercise demonstrates how small, clear tests and defensive coding habits reduce risk in AI projects.

## 🎯 Objectives
- Create a isolated and reproducible environment used a virtual environment (venv) of Python
-  Using the Pandas Library analyse the data of room temperature automaticatlly
- Automatically generate the temperature variation report, which clearly define the temperature deviation


## 📋 Deliverables
1. Virtual environment (venv) of Python (Sandbox)
2. Documented project repository including README.md
3. requirements.txt
4. scripts (temperature_monitor.py)
5. Temperature Breach report (Temperature_variation_report.xlsx)
6. Brief analysis which shows the benefits of automation
